Software Engineering

Concepts and mental models first, implementation later. A living book spanning the full curriculum — Foundations, Systems, Mathematics, Software Engineering, Theory, and chosen specializations. Nothing here is treated as finished; everything is revisited for depth over time.

How to read this: Pick a curriculum below, then a topic — each page stands alone but links to what it naturally connects to. See Teaching Style for how this book is meant to be used, and Review Schedule for what's due for a recall check.
