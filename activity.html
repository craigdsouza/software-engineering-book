Study Activity

A day-by-day log of teaching and quiz events across every curriculum tracked here, in the same shape as a GitHub contribution graph. Built from events.json — the same event log used by the life-os knowledge-graph project, merged here under the book: node namespace.

Two sources, one log: events prefixed concept: come from the life-os vault (Claude teaching sessions on the knowledge graph); events prefixed book: come from tutoring sessions in this book. They share one timeline so a full picture of study activity shows in one place, but book: quiz events don't carry the leveled Recall→Explain→Predict→Design mastery scoring that life-os quizzes do — see the note on the data below.

How this is built

Each square is one calendar day (UTC), colored by how many events — teaching sessions and quiz attempts combined — landed on it. This page loads events.json directly in the browser, so it reflects whatever is in that file at the time it's viewed; no separate build step regenerates it.

Book-sourced quiz_answered events record questions_asked/correct/wrong/gaps but omit score, max_level_reached, and level_breakdown — those fields depend on life-os's leveled mastery formula (5-in-a-row per level to advance Recall→Explain→Predict→Design), which book tutoring sessions don't follow. Rather than fabricate numbers to fit the schema, those fields are left off entirely for book: events.
