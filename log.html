GitHub token (this device)

Submitting creates one file in the repo's inbox/ folder, so this page needs a GitHub token. Create a fine-grained token at github.com/settings/personal-access-tokens/new with access to only craigdsouza/software-engineering-book and one permission: Contents: Read and write. It is kept in this browser only (localStorage) and sent only to api.github.com.
